# Ideas

- issue creation ML workflow
- Slogan: never hesitate to create an issue.


### Power notes

single document, like a todo list, where you can type, then select any text or todo item and convert it to the issue. You can copy paste the whole banch of them, convert into subissues. It should be transactional, (press explicit commit, detect unsaved changes). It should use plain ols NSTextView, issue statuses and checkboxes should be rendered slightly off editable canvas on the left. Other information metadata on the right. Basically a hiercical nested lists.


### Progress report

a lit of opened issues on you with already pre-opened comment fields and most common status changes + ability to invoke agents that analyze local changes. So you can open this view and quickly write what blocks you or what progress you have for it.
